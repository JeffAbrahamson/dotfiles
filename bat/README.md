# bat

Configuration for [`bat`](https://github.com/sharkdp/bat), installed as
`~/.config/bat/config`.

At install time, the installer asks the local `bat`, `bcat`, or `batcat`
executable which themes it supports.  It prefers `Solarized (light)` and
falls back to `OneHalfLight`.  If neither theme is available, installation
fails without replacing an existing configuration.
